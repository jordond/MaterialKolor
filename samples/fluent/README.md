# Fluent sample

The [Tasks sample](../README.md) built on [Compose Fluent](https://github.com/compose-fluent/compose-fluent-ui).
`material-kolor-fluent` turns the seed into the accent ramp Fluent themes from.

Run it with `./gradlew :samples:fluent:run`.
