# Custom theme sample

The [Tasks sample](../README.md) built on Compose Foundation with hand-rolled components. No design
system library is involved. `material-kolor-core` builds tonal ramps from the seed, and the sample
maps them into its own `AppColors`.

Run it with `./gradlew :samples:custom-theme:run`.
