# Material 3 sample

The [Tasks sample](../README.md) built on Compose Material 3. `DynamicMaterialTheme` from
`material-kolor-material3` generates the `ColorScheme` from the seed, and every component reads its
colors from `MaterialTheme.colorScheme`.

Run it with `./gradlew :samples:material3:run`.
