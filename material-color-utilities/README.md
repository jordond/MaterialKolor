# material-color-utilities

This is Google's [Material Color Utilities](https://github.com/material-foundation/material-color-utilities)
for Kotlin Multiplatform. MaterialKolor's other modules are built on it. Use it on its own if you only need the color engine.

```kotlin
implementation("com.materialkolor:material-color-utilities:6.0.0")
```

The source is generated from upstream's Kotlin at a pinned revision. [`docs/upstream-psi.md`](../docs/upstream-psi.md) lists every change the generator makes.
